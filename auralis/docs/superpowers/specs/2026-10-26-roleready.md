# RoleReady end-to-end design
Build the previously discussed local interview coach for any IT job description. Python FastAPI serves a vanilla JavaScript frontend. SQLite stores owner-scoped sessions. Groq supplies GPT-OSS-20B structured JSON and Whisper audio transcription. Browser speech synthesis speaks questions. No Node runtime required.

Features: editable CV/JD intake and PDF/DOCX/TXT extraction; interview/coaching modes; English/Hindi choice; configurable duration; CV claims; rubric before interview; branching scenarios with fixed facts; candidate clarification; hints in coaching; adaptive difficulty with explanation; evidence-linked report; answer replay; same-rubric repair and parallel retry; role comparison; history/export/delete; optional REA JSON evidence import. Arbitrary roles use live AI; deterministic demo scenarios are explicitly illustrative and never scored as real assessment.

Constraints: local single-user deployment; server-side environment key; no automatic paid fallback; no claims of verified authorship, emotion, personality, hiring probability or comprehensive practical skill verification. Audio is ephemeral. Live transmission requires acknowledgement. No public publishing without destination/account. Session changes must be atomic on provider failure, idempotent, owner scoped, deadline and turn limited. Extracted documents and answers are untrusted data. Sources and quotations validated mechanically; judgments remain model-generated.
