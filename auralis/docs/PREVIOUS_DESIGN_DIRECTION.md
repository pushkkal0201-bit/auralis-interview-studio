# Auralis premium edition

A focused interview practice workspace for candidates: prepare a CV and job description, practice with voice or text, review evidence and retry. Existing local-first Python/FastAPI architecture, provider choices, consent, session ownership and assessment disclaimers remain authoritative.

## Direction
Charcoal studio surfaces, warm ivory Manrope typography and restrained botanical mint. The first view is an introduction to the practice task, with a clearly labelled illustrative question. No fabricated scores, user counts, testimonials or claims. Forms, controls and report content retain their original IDs and data contracts.

The setup screen uses two parallel source panels; optional CodeProof and incident evidence follow. Navigation remains visible and labelled. Tablet and phone layouts stack controls, retain native form affordances and avoid hover-only features. All original workflow buttons remain reachable.

## Sources applied
- https://github.com/emilkowalski/skills — emil-design-eng: immediate press feedback, explicit transition properties, fast easing, avoid repeated distracting animations.
- https://github.com/iart-ai/motion-skills — linked web-animation-skills pack, micro-interaction and accessible-animation: brief CSS-based motion, reduced-motion gating, no continuous decorative loop or scroll hijacking.
- https://github.com/pbakaus/impeccable — craft-floor and polish: hierarchy, legibility, focus, responsive states and holistic workflow checks.
- https://github.com/Leonxlnx/taste-skill — app-screens and workspace direction draw: flat tonal panels, sparse accent, honest content, preserved stack and controls. The editorial workspace composition is mapped to the existing dark practice context; its inbox/data suggestions are inapplicable to a CV form. No fictitious datasets were added.

These repositories informed the implementation. They are not browser dependencies or installed global skills. Runtime uses only local CSS, JS and a locally bundled Manrope font (OFL in app/static/fonts).

## Motion
One introductory composition uses a 10px entrance and a short waveform animation ending within four seconds. Buttons use 140ms press response. Reduced motion removes displacement and waveform animation, retaining short color transitions. Existing programmatic scroll respects the same preference. No animation gates functionality.

## Maintenance
premium.css is screen-scoped so the original 3.3 concise/full print rules remain intact. premium.js handles only demo shortcut and navigation accessibility. app.js changes only the two scrolling preferences; assessment, export, replay and provider behavior remain unchanged. The original WebP concept assets remain available but are no longer displayed as interface screenshots.
