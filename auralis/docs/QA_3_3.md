## Standard regression suite

Run inside the `auralis` directory after `setup.bat`:

```bat
.\.venv\Scripts\python.exe -m pytest -q
```

73 automated Python tests passed in the packaging environment. Added tests cover both repeated material-property and GD&T questions seen in the 3.2 synthetic mechanical interview; distinct follow-ups still pass; fallback events do not log provider exception text; synthetic provenance; honest 3->4 score gaps; question-source metadata; and stored-session endpoints.

## Optional standalone Chromium print QA

This script uses **synthetic local report data** and does not call Groq, send CVs online, or interact with your real SQLite database. It renders an assessment with 4 competency cards and 12 long answers to two PDFs and verifies that their contents include expected labels.

Optional QA-only dependencies (not required to run Auralis):

```bat
.\.venv\Scripts\python.exe -m pip install playwright pymupdf
.\.venv\Scripts\python.exe -m playwright install chromium
.\.venv\Scripts\python.exe tests\browser_print_qa.py
```

The generated files go to `_print_qa_output` (not part of the product ZIP). The packaging-environment fixture rendered 4 pages in compact mode and 11 pages in full-replay mode. **Other machines, fonts and interview lengths will produce different page counts.**

## Manual live integration checklist

1. Check `/api/health` returns version `3.3.0` and the selected key is configured (configuration does not mean authenticated).
2. Click the selected real model check, then create a fresh Groq GPT-OSS interview. Confirm one generated plan, context-specific question, answer-driven follow-up, final scored report.
3. Select "fictional or synthetic test data" for fabricated CVs and confirm claim provenance.
4. Use an incorrect engineering answer followed by a correct explanation. Verify score trajectory and evidence IDs.
5. Trigger or simulate a provider rate limit and confirm fallback events show a safe category, not credentials or raw provider exceptions.
6. Inspect the last 2-3 follow-ups for redundant paraphrases; look for an explicit revisit label if the competency was already covered.
7. Print compact and full replay from the browser; full replay must include the Interview X-Ray rationale and formatted answers.
8. Check old 3.2 sessions still load. Legacy reports without score-gap explanations should say that the explanation was not recorded.
9. Manual security review is still required before public deployment. The included automated suite is not a pentest.
