# Auralis practice assessment rubric
- 0: materially incorrect explanation with relevant observed evidence.
- 1: fragmentary account, essential mechanism missing.
- 2: partly correct, important gap or unsupported assumption.
- 3: justified solution that addresses the question.
- 4: correct solution with relevant trade-offs and verification strategy.
- NULL: not tested, insufficient evidence, or only an unverifiable claim.
Scores evaluate only evidence in the submitted answer transcripts, not a candidate's actual employability.
