# Auralis Learning Studio — Visual System

The 5.1 learning tools inherit Studio 4's editorial layout system. They are not a separate dashboard theme.

- **Palette**: warm paper `#F1EEE5`, forest charcoal `#27332D`, muted olive `#858B67`; accessible derivatives for panels and borders.
- **Typography**: Bodoni Moda editorial display; DM Sans practical controls and text; IBM Plex Mono labels, data and provenance.
- **Interaction hierarchy**: report repair begins with rubric and original evidence, then a user-initiated retry; progress displays a real observation count before any chart; the calculator shows assumptions left and result right.
- **Information integrity**: no sparkle icons, ungrounded percentage-of-success claims, fabricated hiring predictions or inferred proficiency graphs. Every source label specifies model-generated vs formula-generated vs saved user content.
- **Responsive behavior**: side-by-side comparison on wide screens; stacked original/revised responses on mobile. Forms become single-column below 600px. Progress chart labels include accessible text alternatives.
- **Printing**: learning tools are excluded from the concise and full-replay print views so older export styles remain intact.
